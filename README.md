一个给用户提供音频输出通道选项的闹钟app。

软件使用Material UI 3主题与控件，兼顾简约和美观。

## 设计初衷 ##

Android闹钟音频输出采用了强制外放的设计，即使设备接有耳机。通常情况下这样的设计可以“让用户一定能够接到通知”，然而在某些需要安静的场合（如宿舍、课堂等），有些闹钟的“重要性”达不到这个水平，用户也并不需要外放。所以，上述设计会带来麻烦。

本软件给用户提供了**自主选择响铃通道**的选项，用户可以自主选择“一定能让我听到响铃”“只通过耳机响铃，如果耳机断连了，我可以接受听不到铃声”等等个性化的选项。

此外，目前手机闹钟软件的UI设计，要么是向玻璃拟态“一边倒”，要么是较为臃肿（第三方app）。本软件的M3 UI提供了另一种选择。

## 注意事项 ##

对于厂商定制Android系统，软件运行需要额外权限（包括但不限于“发送全屏通知”“开启屏幕”“自启动”等），软件首次启动页面也有说明和引导。

请通过 设置 -> 权限管理/应用管理/电池 寻找上述这些选项。在某些特殊情况下，由于系统特性，您可能需要模拟一次闹钟响铃的过程，权限申请窗口才会出现。软件启动页面“授予锁屏显示”部分会引导你完成授权。
